# Building Software with Agents

A self-paced course on directing coding agents to build and ship full-stack web apps. The course follows the projects of the GSG Code Academy curriculum, and an agent writes the code while the student designs, constrains, reviews and fixes it.

Open the course at [lessons/index.html](lessons/index.html), or on GitHub Pages at https://bootcamp-we-have-at-home.github.io/learning-building-with-agents/.

Modules 0 and 1 are built. Modules 2 to 6 are listed on the index as "Soon".

For teaching agents, the instructions are in `AGENTS.md`, and the lesson contract is in `lessons/STYLE.md`.
